# بوت تيليجرام للمساعدة في التوظيف

بوت يساعدك في:
1. **📄 بناء سيرة ذاتية احترافية** — يسألك عن بياناتك، يصيغها بذكاء اصطناعي، ويطلع لك ملف PDF.
2. **🧭 المرشد المهني** — شات مفتوح لنصائح مهنية مبنية على سيرتك الذاتية.
3. **✉️ التقديم على وظيفة** — تعطيه إيميل جهة التوظيف + المسمى الوظيفي، يسوي مسودة إيميل تقديم مع إرفاق سيرتك، **ولا يرسل إلا بعد ما توافق بالضغط على زر "إرسال"**.

---

## 1. المتطلبات

- Python 3.10 أو أحدث
- حساب تيليجرام لإنشاء بوت
- مفتاح Anthropic API (لتشغيل Claude)
- إيميل يدعم SMTP للإرسال (Gmail مثلاً)

## 2. خطوات التشغيل

### أ. إنشاء بوت تيليجرام
1. افتح تيليجرام وابحث عن [@BotFather](https://t.me/BotFather)
2. أرسل `/newbot` واتبع التعليمات
3. راح يعطيك **توكن** — احفظه

### ب. الحصول على مفتاح Anthropic API
اذهب إلى [console.anthropic.com](https://console.anthropic.com) وأنشئ مفتاح API.

### ج. تجهيز إعدادات الإيميل (Gmail كمثال)
1. فعّل **التحقق بخطوتين** في حساب Gmail
2. اذهب إلى إعدادات الأمان → **App Passwords** وأنشئ كلمة مرور تطبيق جديدة
3. استخدم هذي الكلمة (وليس كلمة مرور حسابك العادية) في `SMTP_PASSWORD`

### د. تجهيز المشروع
```bash
cd telegram_job_bot
python -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

### هـ. إعداد ملف البيئة
```bash
cp .env.example .env
```
افتح `.env` وعبّي القيم:
```
TELEGRAM_BOT_TOKEN=توكن_البوت
ANTHROPIC_API_KEY=مفتاح_Claude
SMTP_USER=your_email@gmail.com
SMTP_PASSWORD=app_password_من_خطوة_ج
```

### و. دعم الخط العربي في PDF (مهم)
حمّل خط عربي مجاني مثل [Amiri](https://fonts.google.com/specimen/Amiri) أو
[Noto Naskh Arabic](https://fonts.google.com/noto/specimen/Noto+Naskh+Arabic)،
وضع ملف الخط (بصيغة `.ttf`) داخل مجلد `fonts/` بالاسم:
```
fonts/arabic.ttf
```
بدون هذا الخط، السيرة الذاتية بتطلع بخط لاتيني فقط ولن تدعم العربي بشكل صحيح.

### ز. التشغيل محلياً (للتجربة فقط)
```bash
python bot.py
```
افتح البوت بتيليجرام وأرسل `/start`.

## 3. النشر أونلاين على Render (الطريقة الموصى بها)

البوت مضبوط يشتغل بوضعين تلقائياً:
- **محلياً** (على جهازك): وضع Polling العادي
- **على Render**: يتحول تلقائياً لوضع **Webhook** (تيليجرام يرسل له مباشرة، وهذا أنسب لخدمات الويب مثل Render)

ما تحتاج تغيّر أي شي بالكود — التحويل يصير تلقائياً حسب متغيرات البيئة اللي يضبطها Render نفسه.

### الخطوات

**أ. ارفع المشروع على GitHub**
```bash
cd telegram_job_bot
git init
git add .
git commit -m "أول نسخة من بوت التوظيف"
```
أنشئ مستودع جديد على GitHub وارفع الكود له (`git remote add origin ...` ثم `git push`).

> ⚠️ تأكد إن ملف `.env` **غير مرفوع** (فيه مفاتيحك السرية) — أضفه لملف `.gitignore`:
> ```
> .env
> job_bot.db
> generated_cvs/
> venv/
> ```

**ب. أنشئ خدمة على Render**
1. سجل دخول على [render.com](https://render.com)
2. اضغط **New +** → **Blueprint**
3. اربط مستودع GitHub اللي رفعت له الكود
4. Render راح يكتشف ملف `render.yaml` تلقائياً ويجهز الخدمة (Web Service + قرص تخزين دائم)

> إذا ما استخدمت طريقة Blueprint، أنشئ **Web Service** يدوياً واختر:
> - Build Command: `pip install -r requirements.txt`
> - Start Command: `python bot.py`

**ج. عبّي المتغيرات السرية**
داخل صفحة الخدمة على Render → **Environment**، أضف:
| المتغير | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من BotFather |
| `ANTHROPIC_API_KEY` | مفتاح Claude |
| `SMTP_USER` | إيميلك (Gmail) |
| `SMTP_PASSWORD` | App Password |

باقي المتغيرات (`DB_PATH`, `CV_OUTPUT_DIR`, `SMTP_HOST`...) معبّاة مسبقاً من `render.yaml`.

**د. تضمين خط عربي**
تأكد إن ملف `fonts/arabic.ttf` مرفوع مع الكود على GitHub (وليس في `.gitignore`)، عشان الـ PDF يدعم العربي على السيرفر.

**هـ. Deploy**
اضغط **Deploy** وانتظر. بعد ما تخلص، Render يعطيك رابط عام (`https://your-app.onrender.com`) — البوت يستخدمه تلقائياً كـ Webhook، ما تحتاج تسويله يدوياً.

جرّب البوت على تيليجرام بإرسال `/start` — إذا رد عليك، كل شي تمام ✅

### ملاحظة عن التخزين الدائم
أضفنا قرص تخزين دائم (`disk` في `render.yaml`) بحجم 1GB يُركّب على `/data`، وقاعدة البيانات وملفات PDF تُحفظ فيه — عشان بياناتك ما تنمسح كل مرة يعيد فيها Render تشغيل الخدمة أو ينشر تحديث جديد. هذا يتطلب خطة Render مدفوعة (Starter فأعلى)؛ الخطة المجانية لا تدعم الأقراص الدائمة ولا تفضل شغالة باستمرار.

## 4. ملاحظات مهمة

- **الخصوصية والأمان**: البوت يخزن بيانات كل مستخدم في قاعدة بيانات SQLite محلية (`job_bot.db`). إذا بتشغّله لأكثر من شخص، تأكد من تأمين السيرفر وعدم مشاركة الملف.
- **الموافقة قبل الإرسال**: البوت مصمم بحيث **لا يرسل أي إيميل تلقائياً** — دائماً يعرض المسودة ويستنى ضغطة "إرسال" منك.
- **حدود SMTP**: بعض مزودي الإيميل (مثل Gmail) يحطون حد يومي لعدد الإيميلات المرسلة عبر SMTP. إذا تخطط لاستخدام مكثف، فكر باستخدام خدمة إرسال متخصصة (SendGrid، Mailgun...) بدل SMTP العادي.
- **التشغيل المستمر**: هذا الكود يشتغل بطريقة polling، يعني لازم يفضل شغال على جهازك أو سيرفر (مثل VPS صغير، أو خدمة استضافة مثل Railway/Render) عشان يستمر يرد على المستخدمين.
- **تحويله لمنتج لأشخاص ثانيين لاحقاً**: البنية الحالية (قاعدة بيانات + فصل واضح بين البوت وطبقة الذكاء الاصطناعي) تسمح لك تضيف لاحقاً: حدود استخدام لكل مستخدم، اشتراكات مدفوعة، أو لوحة تحكم — بدون إعادة كتابة الأساس.

├── database.py           # تخزين بيانات المستخدمين والسير الذاتية
├── ai_client.py           # كل استدعاءات Claude API
├── pdf_generator.py        # توليد ملف PDF للسيرة الذاتية
├── email_sender.py         # إرسال الإيميل عبر SMTP
├── render.yaml            # إعداد Render Blueprint (نشر بضغطة واحدة)
├── Procfile              # بديل لتحديد أمر التشغيل على Render
├── requirements.txt
├── .env.example
└── fonts/arabic.ttf        # (تضيفه أنت) خط عربي لملف PDF
```
